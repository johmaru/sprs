# Sprs ドキュメント

[English](../)

組み込みおよびシステム制御向けに設計された言語 Sprs の、Rust 製コンパイラです。

このプロジェクトは、Rust と Inkwell ライブラリ経由の LLVM を使い、Sprs という独自プログラミング言語向けのごく単純なコンパイラを実装しています。
コンパイラは Sprs のソースコードを LLVM IR に変換し、それを実行用の機械語へコンパイルします。

コンパイラはハイブリッド型付けを使います。
ランタイム値はタグでディスパッチされ、`>>` 注釈は検査用の静的型を保持します。
注釈のないコードは動的なまま、使いやすく保たれます。
型付きポインタ（`Ptr(T)`）が指すのは具象 `StorageRep(T)` layout であり、RuntimeValue `{tag,data}` スロットではありません。[型と束縛](language/types-and-bindings.md) と [メモリ管理](reference/memory-management.md) を参照してください。

このドキュメントはまだ開発中であり、今後変わる可能性があります。

- **リファレンス** の各章では、[プロジェクト設定](reference/project-config.md)、組み込みマクロ、モジュール、メモリ管理、[コンパイルエラー](reference/compiler-errors.md) を列挙します。
- [ランタイム関数](internals/runtime-functions.md) はコンパイラとランタイムの内部実装を文書化しており、言語レベルの API ではありません。
- [貢献](contributing.md) では、ローカル開発環境とドキュメント用コマンドを説明します。
